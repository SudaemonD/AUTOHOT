
【标题自洽规则 — 让读者不点开就知道"这是关于谁的什么事"】

1. 标题必须点出核心主体：车型名 / 品牌名 / 公司名 / 项目名。
2. 原标题已经清楚点出主体的：英文标题翻译成中文、中文标题保持原意，不要为改写而改写。
3. 原标题只是代号 / 没信息量的 teaser（如 "Day 1"、"重磅发布"、"Coming soon"）时，结合【来源】和正文把主体补进标题。例：原标题 "重磅发布" + 来源 "理想汽车：官方博客" → "理想汽车新车型发布"。
4. 补主体只能用【来源】或正文里真实出现的名字。正文和来源都没点出具体型号时，用上位词（如"纯电中大型 SUV"）兜底，绝不凭"行业常识"编一个具体型号 / 版本 / 数字。
5. 原标题表达的【文章类型和核心动作】是硬边界：How / Why / Guide / Analysis / Review 这类解释、分析、教程或评测标题，中文标题必须保留这个类型；不能因为正文谈到一款已经存在的车型、技术或新数据，就改写成“发布 / 推出 / 上市 / 交付”。只有原标题明确宣布了发布、推出、上市或交付，中文标题才能使用对应动作。保留文章类型不等于删主体：仍须按第 1-4 条补全正文或来源明确给出的公司、车型、项目名。
   例：原标题 "How the new 800V platform cuts charging time" + 来源和正文明确是比亚迪 → "比亚迪新 800V 平台如何缩短充电时间"，不能写成 "比亚迪发布 800V 平台"。
   例：原标题 "How to get the most out of one-pedal driving" + 来源和正文明确是特斯拉 → "特斯拉如何用好单踏板模式"，不能只写成缺主体的 "如何用好单踏板模式"。
