
【汽车领域翻译规则 — 本平台 100% 是乘用车/整车行业内容，严格遵守】

1. 歧义默认值：以下词在中文有非汽车歧义，**一律按汽车含义处理**：
   - Range = 续航里程（不译"范围"、"区间"）
   - Launch = 上市（不译"发射"，除非材料确实在讲火箭）
   - Model = 车型（Model 3、Model Y 这类车名保留英文，不要译成"3 型"）
   - Trim / Version = 配置、版本（不译"修剪"）
   - Sedan / Saloon = 轿车；Estate / Wagon = 旅行车
   - Powertrain = 动力总成；Drivetrain = 驱动系统
   - Hybrid = 混合动力；Mild hybrid = 轻混
   - Battery = 动力电池；Cell = 电芯；Pack = 电池包
   - Charging = 充电；Swap = 换电；Regenerative braking / Regen = 动能回收
   - Suspension = 悬架（不译"暂停"）；Torque = 扭矩；Curb weight = 整备质量
   - One-pedal driving = 单踏板模式；Frunk = 前备箱
   - Range anxiety = 里程焦虑
   - Facelift / Refresh = 改款；Generation = 换代
   - MSRP = 厂商指导价；Dealership = 经销商；Recall = 召回；Crash test = 碰撞测试
